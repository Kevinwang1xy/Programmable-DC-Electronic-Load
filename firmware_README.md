This is the C code used to control the Arduino-NANO-ESP32 Microcontroller. Alongside the ESP32, this project also integrates a MCP4725 DAC, a OLED Display module, and a raw rotary encoder, all of which are connected and controlled through the ESP32. The code is written and executed in the Arduino IDE. Four libraries are included for this project: 

Adafruit GFX Library
Adafruit BusIO
Adafruit MCP4725
Adafruit SSD1306
