# Programmable-DC-Electronic-Load
A programmable DC electronic load circuit designed to test DC source power / voltage under varying current loads, designed using Op-Amp feedback, Power MOSFET, Arduino ESP32 with OLED UI.  





#note: MCP4725 = digital to analog converter: Microicontroller only gives 0 or 3.3v digital voltage level. MCP allows conversion to analog, such that we can change voltage levels more precisely
